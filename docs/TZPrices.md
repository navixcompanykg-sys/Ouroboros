# OUROBOROS — Цены и масса: справочник

Единый источник истины для всех условных цен (у.ц.) и масс (у.м.) в игре.  
Используется для расчёта стоимости строительства, ROI шахт/заводов, логистики.

> `*` — предложенное значение, не зафиксированное в основном ТЗ. Требует подтверждения.  
> Криптотокен = 1 у.ц. = 1 ед. водорода (эталон торговли, масса = 0).
