## 1. ОБЪЕКТЫ ГАЛАКТИКИ — ТИПЫ И МАССЫ

| Объект | Масса (у.е.) | Примечание |
|---|---|---|
| Туманность | 1–2 | Базовый газовый объект |
| Астероидное поле | 3–9 | Базовый твёрдый объект |
| Новообразование (звёздные ясли) | 10+ | Промежуточная стадия, рождает звезду через 3 тика |
| Белый карлик | 10–15 | Финальная стадия звезды (только через остывание) |
| Красный карлик | 20–30 | Звезда |
| Жёлтый карлик | 31–60 | Звезда |
| Синий гигант | 61–100 | Звезда |
| Нейтронная звезда | наследуется от остатка | Только через сверхновую синего гиганта |
| Чёрная дыра | 101+ | Только через сверхновую синего гиганта |

**Правило типа:** тип объекта определяется его суммарной массой в момент события согласно таблице.

## 2. ТЕМПЕРАТУРНАЯ СИСТЕМА

### 2.1 Общие принципы

Каждый объект имеет параметр **температура T** в диапазоне 0–1000.

- T ≥ 1000 → коллапс (сверхновая или распад)
- T ≤ 10 → смерть от остывания (кроме синего гиганта)
- Синий гигант — исключение: нагревается (+4.7/тик), не остывает

### 2.2 Температуры и скорости изменения

| Тип | Стартовая T | dT/тик | Жизнь (без внешних факторов) |
|---|---|---|---|
| Красный карлик | 100 | −0.03/тик (потеря массы) + −0.14 (температура) | ~714 тиков |
| Жёлтый карлик | 250 | −0.15/тик (масса) + −0.67 (температура) | ~373 тика |
| Синий гигант | 150 | −0.5/тик (масса) + +4.7 (температура) | ~180 тиков |
| Нейтронная звезда | 500 | −0.34/тик | ~1470 тиков |
| Белый карлик | 50 | −0.01/тик (масса) + −0.05 (температура) | ~1000 тиков |

### 2.3 Потеря массы звёздами (П8)

Каждый тик звезда теряет часть массы — она остаётся как туманность рядом:

| Тип | Потеря массы/тик |
|---|---|
| Красный карлик | −0.03 |
| Жёлтый карлик | −0.15 |
| Синий гигант | −0.5 |
| Белый карлик | −0.01 |
| Нейтронная звезда | 0 |

Потеря накапливается в буфере (дробная часть). Когда буфер ≥ 1 — округляется, и рядом со звездой появляется туманность массой min(потеря, 2). Звезда не падает ниже минимума по массе (10 у.е. для большинства, 1 у.е. для белого карлика).

### 2.4 Коэффициент скорости столкновения (Kv)

```
Kv = clamp(1 + V_rel / 0.9 × 4,  min=1, max=2.5)
```

MAX_KV снижен до 2.5 (было 5) для предотвращения быстрого перегрева галактики.

### 2.5 Формула нагрева при поглощении

```
T_new = T_star + (T_object × Kv) × (mass_object / mass_star)
```

### 2.6 Формула слияния двух звёзд

```
T_new = (T1 × M1 + T2 × M2) / (M1 + M2) × Kv
```

## 3. УНИВЕРСАЛЬНОЕ ПРАВИЛО РАСПАДА — 60/40

Единое правило для всех распадов и взрывов (кроме поглощения ЧД):

- **60% массы** → разлетается 8 осколками (тип каждого определяется его массой по таблице раздела 1)
- **40% массы** → остаток (тип по режиму — см. ниже)

Тип осколка по его массе:
- ≤ 2 у.е. → туманность
- 3–9 у.е. → астероидное поле
- ≥ 10 у.е. → новообразование (запускает рождение звезды через 3 тика)

**Режимы остатка (40%):**

| Режим | Применение | Результат |
|---|---|---|
| `ejecta` | Разлёт из взрыва любой звезды кроме синего гиганта | Тип по массе порции |
| `remnant_nova` | Остаток сверхновой синего гиганта | ЧД (если масса >15 и шанс) или НЗ (если ≥10), иначе астероид |
| `remnant_decay` | Остаток остывшей звезды (T≤10) | Белый карлик (если 10–15 у.е.) или новообразование (>15) или астероид |

**Параметры разлёта:**
- Смещение осколков: 2 у.е. от эпицентра
- Импульс разлёта: 2.0–3.0 у.е./тик (радиальный) поверх скорости источника

**Скорость источника:**
- Режим `decay` (остывание): осколки наследуют скорость умершей звезды
- Режим `explode` (взрыв): скорость источника обнулена, летят только осколки

## 4. ЖИЗНЕННЫЙ ЦИКЛ ЗВЁЗД

### 4.1 Эволюция типа при наборе массы

- Красный карлик (20–30) → при массе 31+ становится **жёлтым карликом**
- Жёлтый карлик (31–60) → при массе 61+ становится **синим гигантом**
- При смене типа звезда **сохраняет текущую температуру**
- Деградация невозможна

### 4.2 Остывание и смерть (T ≤ 10)

Применяется к: красному карлику, жёлтому карлику, белому карлику, нейтронной звезде (кроме синего гиганта).

Результат — правило 60/40 в режиме `remnant_decay`:
- 60% → 8 осколков (тип по массе)
- 40% → белый карлик (масса 10–15) или новообразование (>15) или астероид (<10)

### 4.3 Перегрев и взрыв (T ≥ 1000)

Применяется ко всем звёздам. Механика — правило 60/40 в режиме `explode`:
- Для синего гиганта: остаток в режиме `remnant_nova` → ЧД или НЗ
- Для остальных: остаток в режиме `ejecta` → тип по массе

**Нейтронная звезда при T ≥ 1000** → полный распад на осколки (без остатка).

### 4.4 Нейтронная звезда — особые условия

- Рассыпается если накопленная масса ≥ 101 у.е. (не становится ЧД, именно рассыпается)
- Счётчики смерти НЗ ведутся раздельно: остывание / перегрев / масса≥101

## 5. СВЕРХНОВАЯ СИНЕГО ГИГАНТА

### 5.1 Большие и малые события

**Малые события** (хотя бы один участник с массой < 61) — происходят мгновенно за 1 тик.

**Большие события** (хотя бы один участник с массой ≥ 61) — 2 тика:
- **Тик 0:** объекты помечаются `unstable`, их скорости обнуляются (взрыв стоит на месте). Визуально мигают. На этом тике объект ещё может принять массу при столкновении.
- **Тик 1:** взрыв — правило 60/40, появляются осколки и остаток.

### 5.2 Рождение ЧД или НЗ из остатка (40%)

Зависит от числа ЧД в галактике:

| Число ЧД | Вероятность ЧД |
|---|---|
| < 20 | 100% |
| 20–40 | линейно убывает |
| > 40 | 0% (всегда НЗ) |

Если масса остатка < 10 у.е. → астероид. Если 10–15 → НЗ. Если > 15 → ЧД или НЗ по шансу.

## 6. ЧЁРНЫЕ ДЫРЫ

- Поглощают любой объект полностью (100% массы, без остатка)
- Каждый тик теряют 10 у.е. массы (излучение Хокинга), нагревая ближайшие звёзды в радиусе 5 у.е.
- Медленно дрейфуют от центра (0.1 у.е./тик на 10 у.е. массы)
- При ЧД+ЧД — слияние в одну ЧД с суммарной массой

## 7. СТОЛКНОВЕНИЯ

### 7.1 Скорость нового объекта

**П2: Сохранение импульса** — скорость результата вычисляется как взвешенная по массе:
```
vx_new = (vx_a × m_a + vx_b × m_b) / (m_a + m_b)
vy_new = (vy_a × m_a + vy_b × m_b) / (m_a + m_b)
```
Никакого `cartToVelocity` — орбитальная скорость наследуется физически корректно.

### 7.2 Сводная таблица исходов

| Объект A | Объект B | Суммарная масса | Результат |
|---|---|---|---|
| Туманность | Туманность | 2–4 | Туманность или астероид |
| Туманность | Астероид | 4–11 | Астероид или новообразование |
| Астероид | Астероид | 6–18 | Астероид или новообразование |
| Любой | Звезда | любая | Звезда поглощает, T растёт |
| Звезда | Звезда | ≤ 100 | Слияние → новая звезда |
| Любой (не ЧД) | Любой (не ЧД) | > 100 | Правило 60/40 |
| Любой | ЧД | — | Поглощение без остатка |
| ЧД | ЧД | — | Слияние в одну ЧД |
| НЗ | Любой (итого ≥ 101) | ≥ 101 | НЗ рассыпается |

## 8. СИСТЕМА СЧЁТЧИКОВ И СТАТИСТИКИ

Все счётчики накапливаются с первого тика, отображаются в реальном времени в sidebar.

### 8.1 Состояние на текущий тик

- Объекты по типам (все 9 типов)
- Суммарная масса галактики
- **Средний радиус звёзд** от центра (только звёзды)
- Пул возврата (дефицит массы текущего тика)

### 8.2 Рождения и смерти

- Смерти от остывания (T ≤ 10)
- Смерти от перегрева (T ≥ 1000) / сверхновые
- Среднее число новообразований за тик
- Средний возврат массы за тик

### 8.3 Эволюция звёзд

- Red → Yellow (всего)
- Yellow → Blue (всего)
- Born from formation (всего)

### 8.4 Столкновения (накопительно)

- Cloud × Cloud
- Cloud × Star
- Star × Star
- Star × BH
- BH × BH
- Cloud × BH

### 8.5 Нейтронные звёзды

- Рождений всего
- Смерти: остывание / перегрев / масса≥101
- Средний срок жизни

### 8.6 Чёрные дыры

- Рождений всего
