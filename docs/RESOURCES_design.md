# OUROBOROS — Дизайн ресурсов планет

## Принципы системы

### Шкала концентрации: 0–10 000
Все ресурсы измеряются в условных единицах (у.е.). Распределение использует **квадратичную пропорцию**:

```
value = 10 000 × √(relative_abundance)
```

Это сглаживает крайности и делает редкие ресурсы игрово значимыми.

### Типы истощения
| Тип | Поведение |
|-----|-----------|
| **∞ Бесконечный** | Значение = концентрация/стоимость извлечения. Не уменьшается при добыче |
| **★ Стартовый** | Генерируется при рождении звезды/планеты. Только истощается |
| **♻ Возобновляемый** | Медленно регенерирует (геологические/атмосферные процессы) |
| **🌱 Биогенный** | Возникает только при наличии жизни на планете |

### Типы планет (в игре)
- **Rocky** — каменистая (орбиты 9–17)
- **Ice** — ледяная (орбиты 18–26)
- **Gas** — газовый гигант (орбиты 27–35)
- **Lava** — лавовая, горячая (орбиты 0–8)
- **Bare Core** — голое ядро (`effType = null`): лавовая планета с coreTemp > 100. Кора и атмосфера полностью уничтожены близостью звезды. Источник редчайших металлов.

## ПРОИЗВОДНЫЕ АТМОСФЕРНЫЕ ПАРАМЕТРЫ (0–100 у.е.)

> Атмосфера — **производный показатель** от параметров планеты. Вычисляется детерминированно каждый тик через `computeAtmosphere()`.

### Атмосферное давление
Давление зависит от геологической активности планеты — большинство каменистых тел геологически мёртвы (как Марс, Луна) и имеют тонкую или нулевую атмосферу.

```js
const PBASE  = { lava:50, rocky:20, ice:10, gas_giant:82 };

// Геологическая активность: детерминированно из gen_code + orbit_index
// lava/gas_giant — всегда активны (1.0)
// ice — частично активны (0.15–0.80)
// rocky — полностью случайно (0.0–1.0), ~50% планет геологически мёртвы
const geoActivity = (effType==='lava' || effType==='gas_giant') ? 1.0
                  : effType==='ice'   ? 0.15 + resRand(gc, orb, 99) * 0.65
                  : resRand(gc, orb, 99);  // rocky

const retention = (p.planetMass * 0.55 + p.gravity * 0.45) / 100;
const outgas    = min(1, p.coreTemp / 150);
const solWind   = (starTemp / 300) * (1 - orbitNorm) * 0.4;
const geoFloor  = retention * 6;  // гравитационный минимум без активности
pressure = clamp(geoFloor + (PBASE[eff] + 28*retention + 18*outgas) * geoActivity - 22*solWind, 0, 100);
```

**Следствие**: ~50% rocky-планет имеют pressure < 10 (непригодны для жизни). Lava и gas_giant всегда активны. Ice — промежуточно.

### Азот N₂
```js
const N2FRAC = { lava:0.68, rocky:0.74, ice:0.18, gas_giant:0.04 };
nitrogen = clamp(pressure × (N2FRAC[eff] + coreTemp/200×0.12), 0, 100);
```

### Кислород O₂
Абиотическая база 0–6 (фотолиз воды), плюс биогенный прирост до +30 при наличии жизни:
```js
const abiotic   = clamp(water×0.04 + pressure×0.01, 0, 6);
const bioFactor = min(1, log2(1 + lifeAge / (starLifespan×0.15)));
return abiotic + round(30 × bioFactor);  // O₂ > 20 → дышащая атмосфера
```

### Поверхностная температура (surfTemp, 0–100 у.е.)
Производный параметр — тепло от звезды с учётом орбиты и парникового эффекта атмосферы:
```js
function computeSurfTemp(starTemp, orbitNorm, pressure) {
  const starHeat   = starTemp / 600;                           // норм. по макс. ~540 (НЗ)
  const proxFactor = 1 - orbitNorm × 0.75;                    // ближе → горячее
  const greenhouse = 1 + min(pressure/100, 1) × 0.45;         // атмосфера удерживает тепло
  return clamp(round(starHeat × proxFactor × greenhouse × 100), 1, 100);
}
```

**Интерпретация**: 1 = почти абсолютный ноль, 100 = раскалённая поверхность.

### Поверхностная радиация (surfRad, 0–100 у.е.)
```js
function computeSurfaceRad(starRad, orbitNorm, pressure) {
  const shield     = min(1, pressure/60) × 0.85;
  const distFactor = 1 - orbitNorm × 0.7;
  return clamp(round(starRad × distFactor × (1 - shield)), 0, 100);
}
```
`starRad = computeRAD(star)` — радиационный фон системы (50% температура звезды, 35% близость к БЧД/НЗ, 15% расстояние от центра галактики).

### Bare Core: температура и радиация
Голые ядра на ближних орбитах получают максимальные значения по обоим показателям:
- **surfTemp**: высокая (близкая орбита + нет атмосферного рассеивания), как правило > 70
- **surfRad**: `pressure = 0` → `shield = 0` → `surfRad = starRad × distFactor ≈ 75–100` (летальная)

Жизнь на bare core невозможна (`effType = null` исключён из условий рождения).

## СИСТЕМА ЖИЗНИ НА ПЛАНЕТАХ

### Условия рождения жизни (`computeLifeBirthAge`)

Жизнь зарождается автоматически, если **3 тика подряд** выполняются все условия:

| Условие | Порог | Описание |
|---------|-------|---------|
| `eff_type` | rocky или ice | Не лава, не газовый гигант |
| `water` | ≥ 25 | Жидкая или подлёдная вода |
| `pressure` | 10–75 | Есть атмосфера, но не давящая |
| `surfTemp` | 12–72 | Не заморожено, не кипит |
| Звезда | не neutron_star | — |

**Возврат**: тик рождения жизни (относительно возраста звезды), или `null`.  
Для **white dwarf** — симулирует всю фазу предшественника (RED/YELLOW), возвращает отрицательный `birthAge` если жизнь родилась до перехода в WD.

### Условия выживания жизни (`lifeAlive`)

| Условие | Порог |
|---------|-------|
| `eff_type` | rocky или ice |
| `water` | ≥ 20 |
| `pressure` | 5–80 |
| `surfTemp` | 8–80 (не проверяется для white_dwarf — дормант) |
| `surfRad` | < 70 |

### Наследование жизни: White Dwarf

При трансформации звезды RED/YELLOW → WHITE DWARF:
- Сохраняется `star.progenitor` (тип предшественника)
- `computeLifeBirthAge` для WD итерирует фазу предшественника целиком
- `birthAge` отрицательный → жизнь старше текущей звезды
- В холодной фазе WD (surfTemp < 12) жизнь **дормантная** — не гибнет, но активность близка к нулю

## АКТИВНОСТЬ ЖИЗНИ (`computeLifeActivity`, 0–1)

Текущий уровень жизнедеятельности планеты. Множитель для выработки биогенных ресурсов.

```js
function computeLifeActivity(surfTemp, pressure, water, surfRad, isWD) {
  const tFactor = max(0, 1 - pow((surfTemp - 35) / 40, 2));   // пик ~35°, спад к краям
  const pFactor = pressure < 5 ? 0
                : max(0, min(1, min(pressure-5, 80-pressure) / 25));  // оптимум 20–60
  const wFactor = min(1, water / 50);                           // больше воды = активнее
  const rFactor = max(0, 1 - surfRad / 100);                   // радиация снижает активность
  const base    = tFactor×0.4 + pFactor×0.25 + wFactor×0.2 + rFactor×0.15;
  return isWD ? base × max(0.03, surfTemp / 40) : base;        // WD: дормантный множитель
}
```

**Отображение**: бар ACTIVITY (0–100%) в панели планеты при наличии живой жизни.
- ≥ 60% → **thriving** (зелёный)
- 30–59% → **moderate** (жёлтый)
- < 30% → **low** (коричневый)

## БИОГЕННЫЕ РЕСУРСЫ 🌱

> Возникают только при наличии жизни. После гибели жизни — остаются как **ископаемые** (fossil).

### Формула накопления (логарифмическая)
```js
// lifeAge = currentStarAge - lifeBirthAge
const accumulated = min(1, log2(1 + lifeAge / halfLife)) × maxVal;

// Живая жизнь: масштабируется по активности
val = round(accumulated × activity);

// Ископаемые (вымершая жизнь): полный накопленный объём
val = round(accumulated);
```

### Параметры роста

| Ресурс | Макс. у.е. | halfLife (тики) | minAge (тики) |
|--------|----------:|----------------|----------------|
| WILD BIOMASS | 3 000 | 8 | 0 |
| PHOSPHATES | 3 000 | 25 | 10 |
| CARBONATES | 3 500 | 30 | 15 |
| BITUMENS | 4 000 | 60 | 40 |

**Калибровка**: yellow_dwarf живёт ~187 тиков. При halfLife=8 биомасса достигает 50% за 8 тиков; при halfLife=60 битумы накапливаются треть жизни звезды — реалистично для нефти. Активная планета (activity~0.7) даёт ~70% от накопленного объёма.

### Что происходит при событиях со звездой

| Событие | Эффект |
|---------|--------|
| Звезда охлаждается (T < 10) | surfTemp падает → activity → 0 → биоресурсы иссякают; накопленное остаётся как ископаемые |
| Взрыв сверхновой (Blue Giant) | Мгновенное уничтожение жизни; ископаемые остаются |
| Нейтронная звезда | Жизнь невозможна (жёсткий запрет в коде) |
| Белый карлик | Жизнь дормантна; activity ≈ 0.03–0.1; биоресурсы почти не вырабатываются |
