# OUROBOROS — Дизайн-документ v1
## Этап 1: Генерация галактики и физика

---

## 1. СТРУКТУРА ПРОЕКТА

```
server/
├── galaxy_gen.go     # Генератор галактики — Go, запускается для создания galaxy.json
├── galaxy.json       # Результат генерации — читается браузером
├── galaxy.html       # Визуализация и симуляция — весь фронтенд
├── config.html       # Панель конфигурации — браузерный редактор config.json
├── config.json       # Параметры симуляции — читается при загрузке
├── main.go           # Go HTTP сервер, порт 8080
├── go.mod            # Go модуль (module ouroboros, go 1.26.2)
└── serve.bat         # Быстрый запуск на Windows
```

### Назначение файлов

**galaxy_gen.go** — генератор галактики. Запускается `go run galaxy_gen.go -config config.json`. Создаёт `galaxy.json`. Читает параметры генерации из `config.json`. Поддерживает флаг `-seed N` для переопределения сида.

**galaxy.html** — единый фронтенд. Canvas-симуляция, физика тиков, статистика, управление. Не требует сборки.

**config.html** — браузерный редактор всех параметров симуляции. При сохранении POST-запросом обновляет `config.json` на сервере.

**main.go** — Go сервер. Раздаёт статические файлы, принимает `POST /config` (обновление конфига) и `POST /generate?seed=N` (перегенерация галактики).

## 4. АЛГОРИТМ ГЕНЕРАЦИИ

### 4.1 Спиральные лучи (звёзды)

- 40 лучей, угол между ними π/20 радиан
- Каждый луч разбит на 10 колец по радиусу
- Число звёзд на луч по кольцам: [1, 2, 3, 4, 5, 7, 9, 8, 6, 5]
- До 40 попыток размещения с проверкой минимального расстояния
- Недостающие звёзды добираются случайным размещением

### 4.2 Детерминизм

Все случайные решения используют генератор с фиксированным **сидом = 42** (можно изменить через интерфейс). При одинаковом сиде галактика идентична.

### 4.3 Начальные скорости

Объекты получают круговую орбитальную скорость под гравитацию центрального аттрактора:

```
v = sqrt(G * M_center / r)
vx = -rotDir * v * sin(theta)
vy =  rotDir * v * cos(theta)
```

G = 0.005, M_center = 2000. Это обеспечивает устойчивые орбиты с первого тика.

Направление вращения (rotDir = +1 или −1) выбирается случайно один раз для всей галактики.

## 5. ФИЗИКА

### 5.1 Интегратор движения (Leapfrog, декартовый)

Каждый объект хранит `x, y, vx, vy`. Чистый симплектический интегратор без полярных координат и без ограничений скорости:

```
// Вычислить ускорение от гравитации
[ax, ay] = computeAccelXY(o)

// Half-kick
vx += ax * 0.5
vy += ay * 0.5

// Drift
x += vx
y += vy

// Second half-kick
vx += ax * 0.5
vy += ay * 0.5
```

### 5.2 Гравитация

Действует на все объекты, создаётся:
- Центральным аттрактором (M = 2000 у.е.)
- Синими гигантами
- Чёрными дырами

```
F = M * G / (r² + softening)
```

- G = 0.005
- softening = 1.0
- Максимальный радиус влияния объектов (не аттрактора): 20 у.е.

### 5.3 Граничные условия

- `r < 2 у.е.` (зона хаоса) → поглощение, масса в пул возврата
- Выход за квадрат 100×100 → поглощение, масса в пул возврата
- Никакого отражения или блокировки — объекты могут свободно падать в центр или улетать

## 8. ВОЗВРАТ МАССЫ

Масса не теряется из симуляции — объекты поглощённые зоной хаоса или улетевшие за границу возвращаются как влетающие туманности и астероидные поля.

**Целевая масса** (`targetMass`) фиксируется при загрузке галактики. Каждый тик считается дефицит `targetMass - currentMass` и компенсируется влётом объектов.

**Точки влёта** — предгенерированная последовательность из 360 точек по периметру квадрата, перемешанная по сиду галактики (Fisher-Yates). Цикличный обход — детерминировано, без рандома при влёте. Угол к центру строго по прямой, без разброса.

**Скорость влёта:** 0.8–1.6 у.е./тик к центру + орбитальная составляющая 0.3 у.е./тик.
