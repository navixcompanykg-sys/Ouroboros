## 1. СТРУКТУРА ПРОЕКТА

```
server/
├── galaxy_gen.go     # Генератор галактики — Go, запускается для создания galaxy.json
├── galaxy.json       # Результат генерации — читается браузером
├── galaxy.html       # Визуализация и симуляция — весь фронтенд
├── config.html       # Панель конфигурации — браузерный редактор config.json
├── config.json       # Параметры симуляции — читается при загрузке
├── main.go           # Go HTTP сервер, порт 8080
├── go.mod            # Go модуль (module ouroboros, go 1.26.2)
└── serve.bat         # Быстрый запуск на Windows — собирает ouroboros.exe при первом запуске
```

### Назначение файлов

**galaxy_gen.go** — генератор галактики. Запускается `go run galaxy_gen.go -config config.json`. Создаёт `galaxy.json`. Все параметры генерации читаются из `config.json`. Поддерживает флаг `-seed N` для переопределения сида.

**galaxy.html** — единый фронтенд. Canvas-симуляция, физика тиков, статистика, управление. Не требует сборки.

**config.html** — браузерный редактор всех параметров симуляции. При сохранении POST-запросом обновляет `config.json` на сервере. Загружается с дефолтов из кода; значения из сервера дополняют дефолты через deepMerge (не заменяют). Кнопка «Reset Defaults» возвращает актуальные значения.

**main.go** — Go сервер. Раздаёт статические файлы, принимает `POST /config` (обновление конфига) и `POST /generate?seed=N` (перегенерация галактики).

**serve.bat** — собирает `ouroboros.exe` один раз при первом запуске, при последующих — запускает готовый бинарник. При изменении `main.go` нужно удалить `ouroboros.exe`.

## 2. ПРОСТРАНСТВО ГАЛАКТИКИ

### 2.1 Динамический расчёт размеров

Все размеры поля производны от `GALAXY_R` через формулу:

```
CENTER   = GALAXY_R × 1.25        // центр всегда с буфером 25%
FIELD_SIZE = CENTER × 2           // поле симметрично вокруг центра
```

Пересчёт происходит в `recalcDerived()` при старте и после загрузки конфига. Это значит что смена `GALAXY_R` автоматически обновляет центр, поле, сетку и точки влёта — без правок кода.

### 2.2 Параметры по умолчанию

| Параметр | Значение |
|---|---|
| Радиус галактики `GALAXY_R` | 80 у.е. |
| Центр `CENTER` | 100, 100 у.е. |
| Размер поля `FIELD_SIZE` | 200×200 у.е. |
| Буферная зона до края поля | 20 у.е. |

- Координаты дробные — пространство непрерывное.
- **Центральный аттрактор:** невидимый объект массой 10 000 у.е. в точке CENTER. Создаёт гравитацию для всех объектов. Не участвует в столкновениях и не отображается.
- **Зона хаоса:** радиус 2 у.е. вокруг CENTER — объекты поглощаются, масса уходит в пул возврата.
- За пределами поля `FIELD_SIZE` объекты тоже поглощаются пулом возврата.

### 2.3 Обратная совместимость galaxy.json

При загрузке старого `galaxy.json` с другим центром генерации `applyGalaxy` автоматически определяет старый центр (среднее координат звёзд) и сдвигает все объекты к текущему `CFG.CENTER`. Поля `r` и `theta` из JSON всегда пересчитываются от текущего `CFG.CENTER`.

## 4. АЛГОРИТМ ГЕНЕРАЦИИ

### 4.1 Спиральные лучи (звёзды)

- 40 лучей, угол между ними π/20 радиан
- Каждый луч разбит на 10 колец по радиусу
- Число звёзд на луч по кольцам: [1, 2, 3, 4, 5, 7, 9, 8, 6, 5]
- До 40 попыток размещения с проверкой минимального расстояния
- Недостающие звёзды добираются случайным размещением

### 4.2 Детерминизм

Все случайные решения используют генератор с фиксированным **сидом = 42** (изменяется через интерфейс). При одинаковом сиде галактика идентична.

### 4.3 Начальные скорости

Объекты получают круговую орбитальную скорость под гравитацию центрального аттрактора:

```
v = sqrt(G * M_center / r)
vx = -rotDir * v * sin(theta)
vy =  rotDir * v * cos(theta)
```

G = 0.001, M_center = 10 000. Направление вращения (rotDir = +1 или −1) выбирается случайно один раз для всей галактики.

## 6. ФИЗИКА

### 6.1 Интегратор движения (Leapfrog, декартовый)

Каждый объект хранит `x, y, vx, vy`. Симплектический интегратор без полярных координат и без ограничений скорости:

```
[ax, ay] = computeAccelXY(o)   // ускорение от гравитации (0 если o.debris)
vx += ax * 0.5                 // half-kick
vy += ay * 0.5
prevX = x; prevY = y           // сохраняем позицию для хвоста
x += vx                        // drift
y += vy
vx += ax * 0.5                 // second half-kick
vy += ay * 0.5
```

### 6.2 Гравитация

Действует на все объекты кроме тех у кого `debris=true`. Источники гравитации:
- Центральный аттрактор (M = 10 000 у.е.)
- Синие гиганты
- Чёрные дыры

```
F = M * G / (r² + softening)
```

| Параметр | Значение |
|---|---|
| G | 0.001 |
| softening | 1.0 |
| Максимальный радиус влияния объектов (не аттрактора) | 20 у.е. |

### 6.3 Флаг Debris

Объекты с `debris=true` пропускаются в `computeAccelXY` (возвращают [0, 0]).

- Осколки после взрыва (`disperseObject`) получают `debris=true`, `debris_ticks=10`
- Влетающие объекты из пула возврата тоже получают `debris=true`, `debris_ticks=10`
- Туманности от потери массы звезды (`masslossBuffer`) получают `debris=true`, `debris_ticks=10` — предотвращает немедленное падение обратно на звезду
- Каждый тик `debris_ticks` уменьшается; при достижении 0 флаг снимается и объект становится обычным
- При столкновении или поглощении флаг снимается немедленно

### 6.4 Orbital drag (стабилизация орбит)

Каждый тик для каждого объекта (не `debris`, вне зоны хаоса) вычисляется отклонение тангенциальной скорости от оптимальной орбитальной. Пропорционально этому отклонению объект получает малое **радиальное смещение позиции**:

- Тангенциальная скорость выше орбитальной → смещение к центру
- Тангенциальная скорость ниже орбитальной → смещение наружу
- Масштабируется по массе: масса 50 = коэффициент 1.0, тяжелее — сильнее (max 2.0)

```
v_circ = sqrt(G * M_center / r)
v_tang = -vx * sin(theta) + vy * cos(theta)
excess = v_tang - rotDir * v_circ
drift  = -excess * ORBITAL_DRAG * massFactor
x += cos(theta) * drift
y += sin(theta) * drift
```

`ORBITAL_DRAG = 0.02` по умолчанию (настраивается в конфиге). Диапазон: 0.005–0.05. 0 = отключено.

### 6.4 Граничные условия

- `r < 2 у.е.` (зона хаоса) → поглощение, масса в пул возврата
- Выход за `FIELD_SIZE` → поглощение, масса в пул возврата
- Никакого отражения — объекты могут свободно падать в центр или улетать

## 8. ТЕМПЕРАТУРНАЯ СИСТЕМА

### 8.1 Общие принципы

Каждый объект имеет параметр **температура T** в диапазоне 0–1000.

- T ≥ 1000 → коллапс (взрыв или распад)
- T ≤ 10 → смерть от остывания (кроме синего гиганта)
- Синий гигант — исключение: нагревается (+4.7/тик), не остывает

### 8.2 Температуры и скорости изменения

| Тип | Стартовая T | dT/тик | Жизнь (без внешних факторов) |
|---|---|---|---|
| Красный карлик | 100 | −0.03 (масса) + −0.14 (темп.) | ~714 тиков |
| Жёлтый карлик | 250 | −0.15 (масса) + −0.67 (темп.) | ~373 тика |
| Синий гигант | 150 | −0.5 (масса) + +4.7 (темп.) | ~180 тиков |
| Нейтронная звезда | 500 | −0.34/тик | ~1470 тиков |
| Белый карлик | 50 | −0.01 (масса) + −0.05 (темп.) | ~1000 тиков |

### 8.3 Потеря массы звёздами

Каждый тик звезда теряет часть массы — она остаётся как туманность рядом:

| Тип | Потеря массы/тик |
|---|---|
| Красный карлик | −0.03 |
| Жёлтый карлик | −0.15 |
| Синий гигант | −0.5 |
| Белый карлик | −0.01 |
| Нейтронная звезда | 0 |

Потеря накапливается в буфере (дробная часть). Когда буфер ≥ 1 — рядом появляется туманность массой min(потеря, 2). Звезда не падает ниже минимума (10 у.е. для большинства, 1 у.е. для белого карлика).

### 8.4 Коэффициент скорости столкновения (Kv)

```
Kv = clamp(1 + V_rel / 0.9 × 4,  min=1, max=2.5)
```

### 8.5 Формула нагрева при поглощении

```
T_new = T_star + (T_object × Kv) × (mass_object / mass_star)
```

Коэффициенты тепла объектов:
- Туманность: `nebula_temp_per_mass = 5` (у.е. температуры на у.е. массы)
- Астероидное поле: `asteroid_temp_per_mass = 1`

### 8.6 Формула слияния двух звёзд

```
T_new = (T1 × M1 + T2 × M2) / (M1 + M2) × Kv
```

## 9. УНИВЕРСАЛЬНОЕ ПРАВИЛО РАСПАДА — 60/40

Единое правило для всех распадов и взрывов (кроме поглощения ЧД):

- **60% массы** → разлетается 8 осколками (тип каждого определяется его массой)
- **40% массы** → остаток (тип по режиму — см. ниже)

**Тип осколка по его массе:**
- ≤ 2 у.е. → туманность
- 3–9 у.е. → астероидное поле
- ≥ 10 у.е. → новообразование

**Режимы остатка (40%):**

| Режим | Применение | Результат |
|---|---|---|
| `ejecta` | Разлёт из взрыва любой звезды кроме синего гиганта | Тип по массе порции |
| `remnant_nova` | Остаток сверхновой синего гиганта | ЧД или НЗ по шансу, иначе астероид |
| `remnant_decay` | Остаток остывшей звезды (T≤10) | Белый карлик (10–15 у.е.) / новообразование (>15) / астероид |

**Параметры разлёта:**
- Смещение осколков: 2 у.е. от эпицентра
- Импульс разлёта: фиксированный **1.0 у.е./тик** по направлению разлёта (без наследования скорости источника)
- 8 направлений с шагом 45°
- Все осколки получают `debris=true`, `debris_ticks=10`

**Скорость источника:**
- Режим `decay` (остывание): остаток наследует скорость умершей звезды
- Режим `explode` (взрыв): скорость источника обнулена

## 10. ЖИЗНЕННЫЙ ЦИКЛ ЗВЁЗД

### 10.1 Эволюция при наборе массы

- Красный карлик (20–30) → при массе 31+ становится **жёлтым карликом**
- Жёлтый карлик (31–60) → при массе 61+ становится **синим гигантом**
- При смене типа звезда **сохраняет текущую температуру**
- Деградация невозможна

### 10.2 Поглощение мелкого объекта звездой

При столкновении звезды с туманностью, астероидом или другим не-звёздным объектом — два случая:

**Случай A — тип звезды не изменился** (`newStarType === star.star_type`):
- Звезда **мутирует на месте** — обновляются `mass`, `star_type`, `temp`, `x`, `y`, `vx`, `vy`
- `id` и `age` **сохраняются** (возраст не сбрасывается)
- Уничтожается только поглощённый объект
- `masslossBuffer` для `star.id` сохраняется, удаляется только `other.id`
- Если температура после поглощения ≥ 1000 — взрыв на месте без пересоздания

**Случай B — тип изменился** (RED→YELLOW, YELLOW→BLUE):
- Звезда пересоздаётся через `makeObject`, но `age` копируется из старого объекта
- Оба старых объекта уничтожаются

### 10.3 Остывание и смерть (T ≤ 10)

Применяется к: красному, жёлтому, белому карликам, нейтронной звезде (не к синему гиганту).

Правило 60/40, режим `remnant_decay`:
- 60% → 8 осколков
- 40% → белый карлик (10–15 у.е.) / новообразование (>15) / астероид (<10)

### 10.4 Перегрев и взрыв (T ≥ 1000)

Применяется ко всем звёздам. Правило 60/40, режим `explode`:
- Для синего гиганта: остаток в режиме `remnant_nova` → ЧД или НЗ
- Для остальных: остаток в режиме `ejecta` → тип по массе

**Нейтронная звезда при T ≥ 1000** → полный распад на осколки без остатка (режим `ejecta`, явно).

### 10.5 Нейтронная звезда — особые условия

- Рассыпается если накопленная масса ≥ 101 у.е. (не становится ЧД — именно рассыпается, режим `ejecta`)
- Счётчики смерти НЗ ведутся раздельно: остывание / перегрев / масса≥101 / поглощение ЧД

## 11. СВЕРХНОВАЯ СИНЕГО ГИГАНТА

### 11.1 Большие и малые события

**Малые события** (все участники с массой < 61) — происходят мгновенно за 1 тик.

**Большие события** (хотя бы один участник с массой ≥ 61) — 2 тика:
- **Тик 0:** объект помечается `unstable`, скорость обнуляется, визуально мигает. На этом тике ещё может принять массу.
- **Тик 1:** взрыв — правило 60/40.

### 11.2 Рождение ЧД или НЗ из остатка (40%)

Выбор детерминированный (без `Math.random`), зависит от текущего числа ЧД в галактике:

| Число ЧД | Результат |
|---|---|
| ≤ `BH_THRESH_MAX` (40) | ЧД (если масса > 15) |
| > `BH_THRESH_MAX` | НЗ |

Если масса остатка < 10 у.е. → астероид. Если 10–15 → НЗ. Если > 15 → ЧД или НЗ по порогу.

## 12. НОВООБРАЗОВАНИЯ (ЗВЁЗДНЫЕ ЯСЛИ)

- Через 3 тика (`FORMATION_TICKS`) рождают звезду. Рождённая звезда получает орбитальную скорость `sqrt(G * M_center / r)` вместо наследования скорости новообразования.
- Если к моменту рождения масса < 20 у.е. (минимум для красного карлика):
  - Новообразование **поглощает ближайшие туманности и астероиды** в радиусе 5 у.е. пока масса не достигнет 20 у.е.
  - Если объектов в радиусе не нашлось — таймер продлевается ещё на `FORMATION_TICKS`
  - Распадается только если так и не набрало массу

## 13. ЧЁРНЫЕ ДЫРЫ

- Поглощают любой объект полностью (100% массы, без остатка)
- Каждый тик теряют 10 у.е. массы (излучение Хокинга), нагревая ближайшие звёзды в радиусе 5 у.е.
- При `mass ≤ 0` ЧД **исчезает**, масса уходит в пул возврата
- Медленно дрейфуют от центра (0.1 у.е./тик на 10 у.е. массы)
- ЧД + ЧД → слияние в одну ЧД с суммарной массой

## 14. СВОДНАЯ ТАБЛИЦА СТОЛКНОВЕНИЙ

| Объект A | Объект B | Суммарная масса | Результат |
|---|---|---|---|
| Туманность | Туманность | 2–4 | Туманность или астероид |
| Туманность | Астероид | 4–11 | Астероид или новообразование |
| Астероид | Астероид | 6–18 | Астероид или новообразование |
| Любой | Звезда | любая | Звезда поглощает на месте (мутация), T растёт |
| Звезда | Звезда | ≤ 100 | Слияние → новая звезда |
| Любой (не ЧД) | Любой (не ЧД) | > 100 | Правило 60/40 |
| Любой | ЧД | — | Поглощение без остатка |
| ЧД | ЧД | — | Слияние в одну ЧД |
| НЗ | Любой (итого ≥ 101) | ≥ 101 | НЗ рассыпается (режим `ejecta`) |

**Скорость результата — сохранение импульса:**
```
vx_new = (vx_a × m_a + vx_b × m_b) / (m_a + m_b)
vy_new = (vy_a × m_a + vy_b × m_b) / (m_a + m_b)
```

## 15. ВОЗВРАТ МАССЫ

Масса не теряется — объекты поглощённые зоной хаоса или вылетевшие за границу возвращаются как влетающие туманности и астероидные поля.

**Целевая масса** (`targetMass`) фиксируется при загрузке. Каждый тик дефицит `targetMass - currentMass` компенсируется влётом объектов.

**Точки влёта** — предгенерированная последовательность из 360 точек по периметру `FIELD_SIZE`, перемешанная по сиду галактики (Fisher-Yates). Цикличный детерминированный обход.

**Скорость влёта:** вычисляется от реального радиуса точки влёта:
- Тангенциальная составляющая: 70% от орбитальной `v_circ = sqrt(G * M_center / r_inflow)`
- Радиальная составляющая: 0.3 у.е./тик к центру
- Результат: объект входит с почти орбитальной скоростью и медленно дрейфует внутрь

**Точек влёта:** 800 (периметр 200 × 4 = 800 клеток, шаг ~1.0 у.е. ≤ MIN_DIST — столкновения на влёте исключены).

**Карантин влетающих объектов:** `debris=true`, `debris_ticks=10` — 10 тиков без гравитации.

- Переключается кнопкой Grid

### 16.5 Панель статистики (sidebar)

**Состояние на тик:**
- Текущий тик
- Суммарная масса галактики
- Направление вращения
- Средний радиус звёзд от центра (все типы звёзд)
- Пул возврата
- Статус симуляции и скорость тика
- Число столкновений всего и за последний тик
- Счётчики объектов по 9 типам

**Смерти:**
- Cooled (T ≤ 10)
- Overheated (T ≥ 1000) — включает сверхновые (отдельный счётчик `supernovae` в коде не отображается)

**Эволюция:**
- Red→Yellow, Yellow→Blue, Born from formation
- Avg formations/tick, Avg return/tick

**Столкновения (накопительно):**
- Cloud×Cloud, Cloud×Star, Star×Star, Star×BH, BH×BH, Cloud×BH

**Средние температуры по типам звёзд**

**Velocity Stats** — панель скоростей:
- Avg |v| stars — средняя скорость звёзд
- Avg ω stars — среднее угловое ускорение звёзд
- Max |v| star — максимальная скорость среди звёзд
- Avg |v| clouds — средняя скорость облаков (туманности + астероиды)

**Avg Lifespan (ticks)** — среднее время жизни по типам звёзд. Учитываются объекты с `age ≥ 5` на момент смерти. Смерть фиксируется при любой причине: остывание, перегрев, поглощение ЧД, масса≥101.

**Нейтронные звёзды:**
- Рождений всего
- Died cooled / overheated / масса≥101 / поглощение ЧД
- Avg lifespan

**Чёрные дыры:**
- Рождений всего

### 16.6 Управление симуляцией

- Кнопки скорости тика: 1 сек / 3 сек / 10 сек / СТОП / 💾 Export
- Переключатель координатной сетки (Grid)
- Ввод сида + кнопка генерации (перегенерирует `galaxy.json` через сервер без перезапуска)
- Кнопка «Перейти к тику N» — мгновенный прыжок (50 тиков за кадр без отрисовки)

## 19. ЗАПУСК ПРОЕКТА

```bash
# Генерация галактики (обязательно после смены galaxy_gen.go или config.json)
cd server/
go run galaxy_gen.go -config config.json

# Go сервер через serve.bat (рекомендуется)
serve.bat
# → соберёт ouroboros.exe при первом запуске, затем стартует мгновенно
# → http://localhost:8080

# Прямой запуск (альтернатива)
go run main.go

# Python сервер (только статика, без /generate и /config)
python -m http.server 8000
```
