# ЧАСТЬ 2: ДОБЫВАЮЩИЕ ПОСТРОЙКИ

## Базовая механика добычи

### Формула выхода за тик

```
output = deposit / K(level)

K(level) = 109 − 9 × level
```

| Уровень | K    | Доля от запасов/тик |
|---------|------|---------------------|
| 1       | 100  | 1 %                 |
| 2       | 91   | 1.1 %               |
| 3       | 82   | 1.2 %               |
| 4       | 73   | 1.4 %               |
| 5       | 64   | 1.6 %               |
| 6       | 55   | 1.8 %               |
| 7       | 46   | 2.2 %               |
| 8       | 37   | 2.7 %               |
| 9       | 28   | 3.6 %               |
| 10      | 19   | 5.3 %               |
| 11      | 10   | 10 %                |
| 12      | 1    | 100 % (весь остаток за тик) |

**Богатая планета → высокий выхлоп. Истощённая → выхлоп падает пропорционально.**

---

### Истощение запасов

Каждый тик шахта снижает **запас месторождения** на величину своего уровня — независимо от объёма добытого:

```
deposit_next = deposit − level
```

**Срок жизни месторождения** (тиков до нуля):
```
lifespan = deposit_initial / level
```

---

### Суммарная добыча за весь цикл жизни

```
Total = deposit² / (level × K)
```

Это ключевая формула стратегического выбора. Высокий уровень шахты даёт **в 8.33× больше ресурсов суммарно**, просто за гораздо более короткий срок.

**Отношение MAX (Lvl 12) / MIN (Lvl 1) = 25/3 ≈ 8.33 — одинаково для любого ресурса.**

Пример: Железо на планете — 2091 ед.

| Уровень | Выход/тик | Срок жизни | Суммарно за цикл |
|---------|-----------|------------|-----------------|
| 1       | 21 ед     | 2091 тиков | **43 723**      |
| 6       | 38 ед     | 349 тиков  | ~145 000        |
| 12      | 2091 ед   | 174 тика   | **364 357**     |

Вывод: **прокачка шахты — это инвестиция с доходностью в 8.3×**, а не просто ускорение. Богатую планету выгоднее разрабатывать высокоуровневыми шахтами — она отдаст принципиально больше.

---

### Категории ресурсов по истощаемости

| Категория | Примеры | Поведение |
|-----------|---------|-----------|
| **Невосполняемые** | Железо, Силикаты, Тугоплавкие материалы, Редкие металлы, Платиноиды, Радиоактивные вещества | Запас уменьшается навсегда. Игрок выбирает: качать быстро сейчас или экономить надолго. |
| **Восполняемые** | Вода, Фосфаты, Карбонаты, Мягкая биомасса, Битумы | Планета медленно регенерирует запас каждый тик. При скорости добычи ≤ скорости восполнения — месторождение бесконечно. |
| **Условно бесконечные** | Дейтерий, Гелий-3, Благородные газы, Вулканические газы, Водород | Запас не уменьшается — всегда считается от максимального значения. Выхлоп постоянен на любом уровне. |

---

### Распределение выхода по ресурсам

Полученный `output` делится пропорционально **% содержания** каждого ресурса в группе данной шахты. Остаток (сумма % < 100%) — **пустая порода** / инертный остаток.

### Пример (Горнодобывающая шахта, каменистая планета, запас Железа = 2091):
```
Уровень 1, K = 100:
  output = 2091 / 100 = 20.91 ≈ 21 ед/тик

Содержание: Железо 40%, Силикаты 30%, Тугоплавкие 15%, Редкие металлы 10%, Платиноиды 3%, Радиоактивные 2%
  Железо              → 21 × 0.40 = 8.4 ед/тик
  Силикаты            → 21 × 0.30 = 6.3 ед/тик
  Тугоплавкие матер.  → 21 × 0.15 = 3.2 ед/тик
  Редкие металлы      → 21 × 0.10 = 2.1 ед/тик
  Платиноиды          → 21 × 0.03 = 0.6 ед/тик
  Радиоактивные вещ.  → 21 × 0.02 = 0.4 ед/тик
  Пустая порода       → 21 × 0.00 = 0.0 ед/тик

После тика: запас Железа = 2091 − 1 (уровень) = 2090
```

## 4 типа планетарных шахт

### 1. Горнодобывающая шахта
**Добывает:** Железо, Силикаты, Тугоплавкие материалы, Редкие металлы, Платиноиды, Радиоактивные вещества
**Остаток:** Пустая порода
**Работает на:** любой планете с поверхностью (кроме Газового гиганта)

### 2. Атмосферный собиратель
**Добывает:** Дейтерий, Гелий-3, Благородные газы, Вулканические газы, Водород
**Остаток:** Базовый водород (низкой чистоты, не идёт в топливо напрямую)
**Работает на:** любой планете с поверхностью (кроме Газового гиганта)

### 3. Биоэкстрактор
**Добывает:** Вода, Фосфаты, Карбонаты
**Остаток:** Инертная органика
**Работает на:** любой планете с поверхностью (кроме Газового гиганта)

### 4. Гидроминеральная ферма
**Добывает:** Битумы, Мягкая биомасса
**Остаток:** Минеральный осадок
**Работает на:** любой планете с поверхностью (кроме Газового гиганта)

> Ограничений по типу планеты нет — шахты строятся везде где есть поверхность. Если ресурс на данной планете отсутствует, шахта просто не добывает его (нулевой % содержания в профиле планеты).

---

## Газовый гигант — особый случай

На газовом гиганте **нет поверхности** — невозможно построить ничего напрямую.

### 4 добывающие орбитальные станции (вместо шахт)

| # | Станция | Добывает | Примечание |
|---|---|---|---|
| 1 | Водородная станция | Водород | Самый доступный, ∞ запас |
| 2 | Дейтериевая станция | Дейтерий | Сепарация из водородного слоя |
| 3 | Гелий-3 станция | Гелий-3 | Редкий, высокая ценность |
| 4 | Станция благородных газов | Благородные газы | Из верхней атмосферы |

Механика добычи — та же формула `output = deposit / K(level)`. Запас условно бесконечный (не уменьшается).

### Остальные постройки на ГГ

Все прочие здания (жилые кварталы, заводы, верфь и т.д.) строятся на **лунах** газового гиганта или орбитальных **станциях**. Стоимость постройки и прокачки — **×2 к базовой цене**.

---

## Стоимость постройки и прокачки шахт и заводов

### Формула
```
Стоимость уровня N  = Base × N × 1.5
Накопленные вложения = Base × 1.5 × N(N+1)/2  =  C₁ × N(N+1)/2
```
Где **C₁ = Base × 1.5** — стоимость первого уровня.  
**Максимальный уровень всех зданий: 12.**

Основу любого строительства составляют **Силикаты** (бетон/стекло/керамика), **Карбонаты** (цемент) и **Битумы** (гидроизоляция) — присутствуют во всех зданиях без исключения. Пропорция базового бетона: Силикаты : Карбонаты : Битумы ≈ 5 : 2 : 1.

# ЧАСТЬ 5: СТАРТОВАЯ МЕХАНИКА — РУЧНАЯ ДОБЫЧА

## Проблема

Всё производство связано цепочками: заводы требуют компоненты, компоненты требуют сырьё, сырьё требует шахты, шахты требуют компоненты для постройки. Без стартового запаса цепочка не запускается.

## Решение — ручной труд игрока

Каждая шахта и каждый завод имеет режим **ручной добычи/производства**:

- Игрок **находится на планете** (посещение в режиме Planet UI)
- Кликает по иконке шахты или завода **один раз за глобальный галактический тик**
- Получает **одну единицу выхода** без затраты каких-либо ресурсов

### Правила ручной добычи

| Параметр | Значение |
|---|---|
| Кулдаун | 1 глобальный галактический тик на постройку |
| Выход | 1 единица (те же пропорции % содержания что и у автоматической) |
| Стоимость | Бесплатно — только присутствие игрока |
| Ограничение | Только при личном посещении планеты |
| Уровень постройки | Не требуется — работает даже без построенной шахты (базовая ручная добыча) |

### Базовая ручная добыча (без построек)

Даже если на планете нет ни одной шахты или завода, игрок может добывать вручную:

- На любой планете доступна **ручная добыча** для каждого типа шахты — кнопки в Planet UI
- Выход: **10 единиц** (эквивалент шахты Lvl 1) — те же пропорции % содержания что у автоматической
- Кулдаун: 1 глобальный тик на каждый тип добычи
- Доступны все 4 типа (горная, буровая, атмосферная, биоэкстрактор) при соблюдении условий планеты

Ручная добыча без построек — это полноценный труд игрока, заменяющий шахту. Разница только в том, что требует его присутствия на планете каждый тик.

Это позволяет с нуля, через несколько посещений разных планет, быстро накопить стартовый запас для постройки первых зданий.

### Логика прогрессии от нуля

```
1. Игрок посещает Rocky-планету
   → ручная добыча: получает Iron / Silicates
   → ещё тики: Refractories, Rare Metals

2. Накопил достаточно Iron + Silicates
   → строит Металлоконструкции вручную (Chemical factory ещё не нужен)
   → Металлоконструкции появляются в складе

3. Имея Металлоконструкции
   → строит первую шахту (Горнодобывающий комплекс Lvl 1)
   → шахта начинает автоматически давать 10 ед/тик

4. Накапливает сырьё автоматически
   → строит первый завод
   → запускает автоматическое производство компонентов

5. Дальше — самоподдерживающийся цикл
```

## Взаимодействие с галактическим тиком

Глобальный тик — единица времени симуляции галактики (настраивается в config.json).
Кулдаун ручной добычи привязан к нему намеренно:
- **Быстрая игра** (короткие тики) → ручная добыча срабатывает часто, старт быстрый
- **Медленная игра** (длинные тики) → ручная добыча редкая, ценность автоматических построек выше

Это создаёт органичный переход от активного микроменеджмента в начале игры к пассивному управлению империей на поздних стадиях.

## Подбор мусора в космосе

Отдельный источник стартовых ресурсов — обломки, астероиды, брошенные объекты в космосе.
**Описание механики — в отдельном разделе ТЗ (TZSalvage, планируется).**

# ЧАСТЬ 7: СКЛАД

## Роль склада

Склад — буфер между добычей, производством и логистикой.

- Шахты → **склад сырья** → заводы
- Заводы → **склад компонентов** → постройки / корабли / содержание
- Пища (избыток) → **склад пищи** → корабли / другие колонии

Вместимость склада ограничена. Расширяется как отдельная постройка (см. TZPlanetUI — Министерство развития).

При переполнении добыча/производство приостанавливаются автоматически.

## Пища на складе

Пища — отдельная категория склада, пополняется двумя путями:

1. **Пищевое производство:** весь объём сверх текущего потребления населения автоматически поступает на склад.
2. **Природная пища (Биоэкстрактор):** **10% от объёма сверх потребления** отгружается на склад. Остальное остаётся в локальном пищевом пуле планеты.

```
избыток_природной = природная_пища_в_тик − потребление_населения
отгрузка_на_склад = floor(избыток_природной × 0.10)
```

Пища на складе **не портится** (консервированная / сублимированная форма).  
Пищу можно **грузить на корабли** и перевозить в другие колонии.

# ЧАСТЬ 8: АВТОМАТИКА И РАСПРЕДЕЛЕНИЕ ПЕРСОНАЛА

## Распределение персонала

Игрок распределяет рабочую силу планеты по 4 категориям через окно экономики.  
Персонал — множитель эффективности зданий своей категории. 0% = здание не работает, 100% = полная мощность.

| Категория | Здания | Логика работы |
|---|---|---|
| **Добыча** | Шахты, Буровые, Атмосферные процессоры, Биоэкстракторы | Добывают сырьё → на склад |
| **Производство / Развитие** | Заводы, очередь строительства зданий | Производят компоненты → строят здания из очереди → излишки на склад |
| **Флот** | Верфь | Строят корабли по очереди судостроения |
| **Энергия / Майнинг** | Энергостанции, Криптоферма | Вырабатывают энергию → избыток направляется в Криптоферму |

## Алгоритм «Производство / Развитие»

```
Каждый тик:
1. Считаем дефицит компонентов для всех 4 слотов очереди строительства
2. Заводы производят компоненты под дефицит (в меру выделенного персонала)
3. Произведённое + остатки со склада → идут на строительство
4. Все 4 слота строятся параллельно
5. Завершённый слот освобождается → следующее здание из очереди занимает слот
6. Если на строительство не хватает — заводы продолжают производить, накапливают на складе
7. Всё произведённое сверх нужного для стройки → на склад
```

> Один пул рабочих рук: одни и те же люди производят компоненты и строят.  
> Если очередь строительства пуста — весь персонал категории производит компоненты на склад.

## Очередь строительства

- **4 слота** — максимум 4 здания строятся одновременно на одной планете
- Игрок задаёт порядок вручную; автоматика исполняет
- Каждый слот независим: нехватка компонентов для одного не блокирует остальные

# ЧАСТЬ 9: НАСЕЛЕНИЕ

## Основные принципы

- **Предел населения** = предел пищевых ресурсов планеты
- **Норма питания**: 1 единица пищи / тик на 1 единицу населения
- **Пища распределяется пропорционально** населению каждого игрока на планете (если планету делят несколько игроков)
- Население **сверх природного лимита** кормится за счёт Пищевого производства

## Население как рабочая сила

### Жильё с первого тика

Жильё строится в **первый же тик** — это первое здание в очереди постройки.  
Стартовый груз содержит все необходимые компоненты.  
K_жильё = 0 только если игрок намеренно проигнорирует постройку жилья.

### Работники и автоматический режим построек
Каждый **уровень постройки** потребляет **1 работника** для работы в автоматическом режиме.

```
Рабочих занято = Σ (уровни всех активных построек на планете)
Свободных рабочих = floor(Pop) − Рабочих занято
```

Постройка без назначенного работника **не производит ничего** автоматически, но может использоваться вручную.

### Ручные действия (bootstrap)
```
Ручных действий в тик = max(1, Свободных рабочих)
```

Каждое ручное действие = одно использование любой постройки или режима добычи:
- Ручная шахта (без постройки): **+10 ед. сырья** по профилю планеты
- Ручная фабрика (без постройки): **+1 компонент** выбранного типа (бесплатно — bootstrap)
- Ручная фабрика (с постройкой, но без рабочего): то же, +1 компонент

> Минимум 1 действие/тик гарантирован — даже одинокий игрок без построек может работать руками.

## Источники пищи

| Источник | Откуда | Лимит |
|---|---|---|
| Природная пища | Биоресурсы планеты (Биоэкстрактор) | Природный лимит планеты |
| Усиленная природная | Природный лимит × (1 + 0.1 × уровень Плантаций) | Ограничен уровнем Плантаций |
| Синтетическая пища | Пищевое производство | Не ограничен (зависит от уровня постройки) |

## Формула прироста населения

```
ΔPop = round(Pop × 0.1 × K_жильё × K_пища × K_рад × K_давл × K_грав × K_загрязн)
```

**0.1 = R_base − 1 = 1.1 − 1** — базовый расовый прирост 10%/тик.  
Каждый фактор — независимый мультипликатор. Все перемножаются.

---

### K_жильё ∈ [0.5 ; 1.5]

```
дефицит = max(0, Pop − вместимость_жилья)
избыток  = max(0, вместимость_жилья − Pop)
K_жильё  = clamp(1 − дефицит × 0.05 + избыток × 0.02,  0.5, 1.5)
```

Дефицит штрафует сильнее (−0.05/чел.), избыток помогает слабее (+0.02/чел.).

| Ситуация | K |
|---|---|
| Дефицит −10 мест | 0.50 (минимум) |
| Дефицит −2 места | 0.90 |
| Баланс (жильё = Pop) | 1.00 |
| Излишек +10 мест | 1.20 |
| Излишек +25 мест | 1.50 (максимум) |

---

### K_пища ∈ [0.5 ; 2.0]

```
ratio = еда_доступно / (Pop × норма_питания)

если ratio ≥ 1.0:  K_пища = clamp(ratio, 1.0, 2.0)
если ratio < 1.0:  K_пища = clamp(ratio, 0.5, 1.0)
```

| ratio | K | Состояние |
|---|---|---|
| ≥ 2.0 | 2.00 (максимум) | Изобилие |
| 1.0 | 1.00 | Норма |
| 0.5 | 0.50 (минимум) | Голод — рост замедлен вдвое |
| < 0.5 | 0.50 (минимум) | Критический голод |

> Один игрок на необжитой планете — ratio ≈ 80. K_пища = 2.0.

---

### Экологические факторы — только штрафуют, диапазон [0.5 ; 1.0]

Идеальные условия → K = 1.0 (нейтрально). Отклонение от нормы → K снижается до 0.5.

**K_радиация** — норма: 0 (шкала планеты 0–100)
```
K_рад = clamp(1.0 − radiation × 0.01,  0.5, 1.0)
```
| Радиация | K |
|---|---|
| 0 | 1.00 |
| 25 | 0.75 |
| 50+ | 0.50 (минимум) |

---

**K_давление** — норма: 1.0 атм
```
K_давл = clamp(1.0 − |давление − 1.0| × 1.0,  0.5, 1.0)
```
| Давление (атм) | K |
|---|---|
| 1.0 | 1.00 |
| 0.5 или 1.5 | 0.50 (минимум) |
| 0 (вакуум) | 0.50 |
| 2.0+ | 0.50 |

---

**K_гравитация** — норма: 1.0 g
```
K_грав = clamp(1.0 − |гравитация − 1.0| × 1.0,  0.5, 1.0)
```
| Гравитация (g) | K |
|---|---|
| 1.0 | 1.00 |
| 0.5 или 1.5 | 0.50 (минимум) |
| 0 или 2.0+ | 0.50 |

---

**K_загрязнение** — норма: 0 (шкала 0–100, только отрицательный)
```
K_загрязн = clamp(1.0 − загрязнение / 100,  0.5, 1.0)
```
| Загрязнение | K |
|---|---|
| 0% | 1.00 |
| 25% | 0.75 |
| 50%+ | 0.50 (минимум) |

---

### Купол (защищённые жители)

#### Раздельный учёт населения

Население планеты делится на **две независимые группы** с отдельными формулами прироста:

| Группа | Жильё | Экология |
|---|---|---|
| **Открытое население** | Жилые кварталы | K_рад, K_давл, K_грав, K_загрязн — все действуют |
| **Купольное население** | Защитные купола | K_давл = K_грав = K_загрязн = 1.0; только K_рад действует |

Прирост считается отдельно для каждой группы и суммируется. Переселение между группами не происходит автоматически.

#### Лимит переполненности купола

Купол рассчитан на **5 жителей за уровень** (стандарт).  
Максимальная вместимость с учётом переполненности — **не более 10 жителей за уровень** (двойная норма).

```
вместимость_купола     = уровень × 5
лимит_переполненности  = уровень × 10
```

Население в куполе **не может превысить лимит переполненности** — прирост останавливается при достижении `уровень × 10`, даже если все прочие K благоприятны.

Радиация проникает через любую защиту — **K_рад действует всегда**.

---

### Диапазон роста

| Условия | K_итог | ΔPop/тик |
|---|---|---|
| Идеальная планета, изобилие еды, много жилья | ~3.0 | Pop × 0.30 |
| Хорошая планета, достаточно еды и жилья | ~1.2–1.5 | Pop × 0.12–0.15 |
| Норма по всем факторам | 1.0 | Pop × 0.10 |
| Нехватка жилья / плохая экология | 0.5–0.8 | Pop × 0.05–0.08 |
| Критические условия (несколько факторов на минимуме) | ~0.06 | Pop × 0.006 (стагнация) |

> Стартовый тройной рост быстро гасится нехваткой жилья — это намеренная механика: первые тики дают буст заселения, затем игрок обязан строить жильё или рост остановится.

# ЧАСТЬ 11: КРИПТОВАЛЮТА

## Криптотокен — эталон торговли

**Курс:** 1 токен = 1 ед. водорода. Фиксировано по всей галактике, не колеблется.

| Параметр | Значение |
|---|---|
| Курс | 1 токен = 1 ед. водорода |
| Масса токена | 0 у.м. (не занимает трюм) |
| Масса водорода | 2 у.м. |
| Производство | Криптоферма — из избытка энергии |
| Обмен | В любой точке галактики 1:1 |

**Смысл:** водород — самый распространённый элемент, универсальное топливо и эталон стоимости.  
Токен — это водород без массы. Удобен для межзвёздных расчётов и торговли без затрат трюма.

**Применение токенов:**
- Торговля между игроками
- Оплата аренды складов
- Любые межпланетные расчёты
- Прямой обмен на физический водород 1:1

> Игрок с профицитом энергии майнит «цифровой водород» и тратит его вместо физического топлива в торговых операциях.

## Правила Ангара

**1 Ангар** — вмещает истребители и бомбардировщики (малые аппараты).  
**N соединённых Ангаров** — вмещает корабль с размерностью ≤ N у.е.:

| Кол-во Ангаров | Вмещает |
|---|---|
| 1 | Истребители / Бомбардировщики |
| 2 | Корвет / Шаттл (1 у.е.) |
| 3–4 | Фрегат / Челнок (2 у.е.) |
| 5–8 | Эсминец / Клипер (4 у.е.) |
| 9–12 | Крейсер / Баржа (8 у.е.) |
| 13–21 | Линкор / Лайнер (12 у.е.) |

**Ангар vs Стыковочный dok:**

| | Ангар | Стыковочный dok |
|---|---|---|
| Размещение | Внутри корпуса | Снаружи |
| Защита от урона | ✅ Полная | ❌ Получает урон вместе с носителем |
| Стоимость слота | 3 740 у.ц. × N | 1 680 у.ц. |
| Применение | Хранение и защита | Быстрая перегрузка, стыковка |
