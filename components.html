Конструктор

Как это устроено

Сырьё→Компонент→Оборудование→Корабль

Параметры принадлежат компонентам, а не оборудованию. У оборудования задаётся только состав — сколько компонентов каждого типа в него входит. Свойства предмета не вводятся, а считаются: параметр = Σ (компонентов в составе × влияние компонента на этот параметр). Уровень компонентов меняет влияние — значит, и свойства предмета. Новое оборудование добавляется одной строкой состава, все характеристики появятся сами.

Сырьё: 4 типа по 3 уровня

Компонент собирается из сырья своего типа

На любой компонент уходит ровно 3 единицы сырья — дорожает не количество, а уровень. Масса идёт по цепочке сама: по правилу v2 (ТЗ_Экономика §8.3) при каждом переделе массы уходит в отходы, поэтому массу вводить не нужно нигде.

1. Влияние компонента на параметры

Сколько даёт один компонент этого типа и уровня. Пустое поле — ноль. Строка «Масса» не вводится: она уже посчитана из массы сырья.

сохраняется автоматически

Энергоёмкость топлива

Энергетическое сырьё — это и есть топливо. Газохранилище сжигает одну единицу за цикл и выдаёт столько энергии, сколько задано здесь; дальше эта энергия тратится оборудованием наравне с выработкой реакторов. Выработка корабля = выработка оборудования + газохранилища × энергоёмкость топлива.

2. Состав оборудования

Сколько компонентов каждого типа входит в предмет. От уровня состав не зависит — уровень выбирается при сборке. Справа — масса предмета по уровням, она следует из состава.

3. Свойства оборудования — выводятся

Ничего не вводится: всё посчитано из состава и влияния компонентов.

4. Итог: три корабля

Дизайны — из конструктора. Уровень — из каких компонентов собран весь корабль. Орудие ставится в каждый оружейный модуль.

Как считается:

  • Ускорение = Σ(«ускорение на 100 т» × 100) ÷ масса корабля × доля энергии. Доля энергии — сколько спроса двигателей закрывает выработка (не хватает — тяга падает кратно). Дальше работают те же формулы, что в полёте (ships.js): ускорение растёт со скоростью как a₀(1 + K(v/c)²).
  • Энергия. У компонентов два расхода: пассивный идёт всегда, активный — только пока модуль работает. При разгоне = пассив всего корабля + актив только двигателей; в бою = пассив + актив всех систем.
  • Пересечение сектора — (пятая часть радиуса галактики) по модели межзвёздного перелёта: разгон до 0,98 c, сверхсветовой скачок, торможение на половине тяги.
