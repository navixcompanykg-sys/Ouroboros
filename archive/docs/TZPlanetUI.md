# ТЗ: Планетарный интерфейс (Planet UI)

## Обзор

Интерфейс открывается при:
- посадке корабля игрока на планету
- двойном щелчке по планете в режиме просмотра галактики

Интерфейс является «стартовой панелью» для всех действий на планете. Сам по себе не несёт игровой механики — только отображает состояние и даёт доступ к разделам.

## 2. Компоненты интерфейса

### 2.1 Название планеты (сверху, по центру)

Формат: `<Имя звезды> #<N>` где N — порядковый номер планеты по удалённости от звезды (начиная с 1).

Пример: `Kepler-42 #3`

Дополнительно (мелко, под названием): тип планеты, например `Terrestrial · Temperate`

---

### 2.2 Планета (центр экрана)

- Круг с градиентной заливкой согласно типу и цвету планеты
- Размер: ~200–260 px в диаметре
- Цвета и визуальный стиль соответствуют типам из генератора (см. galaxy.html):
  - **Terrestrial** — синие/зелёные/коричневые тона, облака
  - **Gas Giant** — полосы, оттенки оранжевого/коричневого/бежевого
  - **Ice Giant** — голубые/синие тона
  - **Desert** — жёлто-оранжевые тона
  - **Ocean** — синий, блики
  - **Frozen** — серо-белые тона
  - **Volcanic** — тёмный с оранжевыми прожилками
  - **Bare Core** — тёмно-серый, металлик
  - **Toxic** — жёлто-зелёный
  - **Lava** — тёмный с красными прожилками

Анимация: медленное вращение (CSS animation, rotate планеты по горизонтальной оси — имитация).

---

### 2.3 Характеристики планеты (слева от планеты)

Панель без прокрутки, 8 ключевых параметров. Без рамки или с тонкой рамкой.

| Параметр | Пример значения | Примечание |
|---|---|---|
| Игроки на планете | 0 | Количество игроков, находящихся на планете в данный момент |
| Население | 0 / Необитаема | Жители колонии (NPC); 0 = необитаема |
| Экология | 87% / Девственная | Состояние экосистемы; снижается от добычи и промышленности |
| Пищевые ресурсы | Умеренные | Оценка: Нет / Скудные / Умеренные / Богатые / Изобильные |
| Радиация | 0.3 Зв/год / Низкая | Фоновый радиационный фон |
| Давление | 1.03 атм | Атмосферное давление |
| Гравитация | 1.01 g | Поверхностная гравитация |
| Атмосфера | Азот-Кислород | Состав атмосферы; «Нет» если вакуум |

Значения берутся из данных генератора планеты. Игроки и население — игровые поля, по умолчанию 0.

---

### 2.4 Орбитальные объекты (справа от планеты)

Слоты под спутники и орбитальные станции. Отображаются в виде кружков, расположенных **вертикально в два столбца**, образующих форму полумесяца (дуга направлена в сторону планеты):

```
     ○  ○
   ○      ○
  ○        ○
   ○      ○
     ○  ○
       ○
```

- **Столбец 1 (ближний к планете):** 5 кружков, вертикальная дуга
- **Столбец 2 (дальний от планеты):** 6 кружков, вертикальная дуга

Расстановка по координатам: кружки располагаются по двум вертикальным дугам, математически описываемым как точки на двух эллипсах с общим центром, смещённым вправо от планеты.

Итого максимум 11 слотов.

Кружок пустой (серый контур) — свободный слот.  
Кружок заполненный — занят спутником или станцией, цвет/иконка зависит от типа объекта:
- Природный спутник — серый/каменный
- Орбитальная станция — синий металлик (строится игроком)
- Военный спутник — красный
- Научный зонд — белый/серебристый

При наведении на заполненный кружок — всплывает подсказка с именем и типом объекта.  
При клике — открывается интерфейс объекта (в будущем).

#### Карточка здания (горизонтальная)

- **Нижняя полоса:** иконки ресурсов с количеством стоимости следующего уровня (красные если не хватает), содержание ⚡X/тик

Всегда видима. Данные берутся из `planet._computed` (заполняется в `openPlanetUI`):

| Секция | Показатели |

| ЭНЕРГИЯ | Производство, потребление, баланс |
| НАСЕЛЕНИЕ | Кол-во, жильё (мест), свободно, рабочих мест, баланс рабочих, прирост/тик |
| МОРАЛЬ | Итого + подфакторы: база, культ. центр, токсичность, радиация, питание, купола, экономика |
| ПИТАНИЕ | Добыча/тик, потребление, баланс, запас |
| ТОКСИЧНОСТЬ | На планете %, выработка/тик, очистка/тик |
| ПРОЧЕЕ | Радиация %, наука/тик, радиус разведки |

#### Детали здания (нижняя часть правой панели)
- При выборе здания: название, уровень, эффект, стоимость следующего уровня с проверкой наличия ресурсов

#### Техническая архитектура
- Модуль: `server/ui/development.js`, экспортирует `open(planet, context)` и `close()`
- Загружается лениво: `import('/ui/development.js?v=' + Date.now())`
- `planet._computed` заполняется в `openPlanetUI` — содержит `surfRad`, `toxicity`, `surfTemp`, `pressure`, `gravity`, `lifeAlive`, `activity`, `effType`, `o2`
- DOM пересоздаётся при каждом `open()` (защита от кеша)
- Все стили инжектируются через JS (`injectStyles()`), CSS-классы не используются

#### Итерации
- **Итерация 1 (текущая):** UI, отображение зданий, кнопка постройки списывает ресурсы из `planet.resources`
- **Итерация 2 (план):** Проверка реальных ресурсов планеты, очередь строительства
- **Итерация 3 (план):** Тик-интеграция, реальные эффекты зданий на экономику

## 4. Генерация спутников

### 4.1 Количество спутников

При генерации планеты добавить поле `moons: number` (0–11).

Формула (псевдокод):

```
base = случайное(0, maxMoons[planetType])
bonus = если масса > 2.0 M⊕: +1..2
penalty = если орбита < 0.3 а.е.: -1..2 (приливный захват)
moons = clamp(base + bonus - penalty, 0, 11)
```

`maxMoons` по типам:

| Тип планеты | maxMoons |
|---|---|
| Gas Giant | 11 |
| Ice Giant | 9 |
| Terrestrial | 4 |
| Ocean | 3 |
| Desert | 2 |
| Frozen | 3 |
| Volcanic | 1 |
| Toxic | 2 |
| Lava | 1 |
| Bare Core | 0 |

### 4.2 Тип спутников

На данном этапе все спутники — природные (rocky moon). Детальная генерация характеристик спутников — в отдельном ТЗ `TZMoons.md`.

Поля спутника (минимальный набор):
```json
{
  "id": "moon_uuid",
  "type": "natural",
  "size": "small | medium | large",
  "color": "#aaa"
}
```

## 5. Открытие интерфейса

### 5.1 Двойной клик по планете (режим просмотра)

- `dblclick` на объекте `planet` в canvas
- Открывает Planet UI поверх галактической карты (overlay)
- Кнопка «Закрыть» (✕) возвращает к карте
- Клавиша `Escape` закрывает интерфейс

### 5.2 Посадка корабля (будущее)

- При получении события `ship_landed` с `planetId` — автоматически открывается Planet UI для этой планеты
- Заголовок получает дополнительный тег `[Посажен: <имя корабля>]`

## 6. Техническая реализация

### 6.1 HTML-структура

**Оболочка Planet UI** — реализована внутри `galaxy.html` как скрытый `<div id="planet-ui">`. Содержит визуал планеты, 8 статов, орбитальные объекты, 10 кнопок-переходов.

**Подразделы** — отдельные JS-модули в `server/ui/*.js`, загружаются лениво через `import('/ui/name.js?v=' + Date.now())` при нажатии кнопки. Каждый модуль экспортирует `open(planet, context)` и `close()`. DOM пересоздаётся при каждом открытии.

`planet._computed` — объект с вычисленными параметрами планеты, заполняется в `openPlanetUI` (galaxy.html) и доступен всем модулям: `{surfRad, toxicity, surfTemp, pressure, gravity, lifeAlive, activity, effType, o2}`.

`main.go` должен раздавать файлы из `ui/` — добавить путь `/ui/` в `handleStatic` или завести отдельный handler с `http.FileServer`.

### 6.2 Данные планеты

Planet UI получает объект планеты из `star_registry.json` / in-memory объекта по `planetId`. Поля, которые должны присутствовать:

```json
{
  "id": "...",
  "name": "Kepler-42 #3",
  "type": "Terrestrial",
  "color": "#4a7a4a",
  "gravity": 1.01,
  "atmosphere": "Nitrogen-Oxygen",
  "pressure": 1.03,
  "radiation": 0.3,
  "foodResources": "moderate",
  "ecology": 87,
  "moons": 2,
  "moonData": [...],
  "population": 0,
  "playersPresent": 0
}
```

### 6.3 Стиль

- Тёмная тема, единый со стилем `galaxy.html`
- Фон: полупрозрачный тёмный overlay `rgba(0,0,0,0.85)`
- Шрифт: тот же что в galaxy.html
- Кнопки верхнего/нижнего ряда: прямоугольные, с иконкой и подписью, стиль аналогичен существующим UI-панелям
- Планета: CSS canvas или SVG-круг с радиальным градиентом

### Элементы левой панели

| Элемент | Описание |
|---|---|
| Строка «Без флота» | Нераспределённые корабли; клик → показ справа с кнопкой «+ Флот» |
| Строка флота | Иконка + имя + кол-во кораблей + % заполненности трюма |
| **🛡 Охранять** | Тоггл. Зелёный когда активен. Флот атакует вражеские флоты при вторжении в систему |
| **💹 Торговать** | Открывает модал настройки (радиус поиска в пк). Флот ищет дефицитные ресурсы (< мин. запаса склада) на ближайших планетах и закупает если цена ≤ базовой на складе |
| **🗺 В путь** | Открывает модал выбора цели (карта галактики — в разработке) и действия по прибытии |
| **🆘 Подкрепление** | Открывает модал настройки (радиус в пк). Флот дежурит и автоматически вылетает в системы в радиусе если туда вторгаются силы превосходящие по мощи союзника или игрока. После боя — возвращается на базу |

### Действия флота «В путь»

| Действие | Условие | Описание |
|---|---|---|
| Приземлиться | — | Флот летит и садится на космодром целевой планеты (по умолчанию) |
| Атаковать | — | Уничтожение вражеских флотов → бомбардировка → высадка десанта. Порядок настраивается. Бомбардировка уничтожает здания и население |
| Пиратствовать | — | Атакует более слабые флоты, избегает равных и сильных |
| Колонизировать | Корабль-«Пионер» в составе | Высадка колониального модуля на необитаемой планете |
| Добывать ресурсы | Горнодобывающее оборудование | Добыча пока трюмы не заполнены, затем возврат |

> Правила войны (приоритеты, бонусы, потери) — в отдельном ТЗ по боевой системе.

### Техническая архитектура (UI)

- `server/ui/spaceport.js` — модуль, `export { open, close }`
- Mock-данные флотов и кораблей в модуле; заменяются серверным API
- Команды сохраняются в `_mockFleets[id].orders` (локально до появления бэкенда)
- Модалы «Торговля» и «В путь» рендерятся как overlay внутри `#planet-ui`
- Карта галактики в модале «В путь» — заглушка, ждёт интеграции с `galaxy.html`
