## 3. Строительство кораблей

### 3.1 Очередь верфи

- Корабли строятся на **Верфи** (здание, TZEconomy §Верфь)
- Строительство идёт в очереди: пока один корабль не достроен, следующий не начинается
- Уровень Верфи определяет максимальный класс корабля, который можно строить:

| Уровень верфи | Максимальный класс |
|---|---|
| 1–2 | Корвет / Шаттл |
| 3–4 | Фрегат / Челнок |
| 5–6 | Эсминец / Клипер |
| 7–8 | Крейсер / Баржа |
| 9–10 | Линкор / Лайнер |
| 11–12 | Дредноут / Танкер |

### 3.2 Шаблон корабля

Перед постройкой игрок задаёт **шаблон**: класс + набор модулей. Верфь строит корабли по шаблону.  
Смена шаблона применяется к **следующему** кораблю в очереди, не к текущему.

Один игрок может иметь до **4 активных шаблонов** на каждый класс (2 боевых + 2 гражданских).

### 3.3 Время строительства

```
Время (тиков) = у.е. × кол-во_модулей × 0.5 / уровень_верфи
```

Пример: Фрегат (2 у.е.), 8 модулей, Верфь ур. 3 → `2 × 8 × 0.5 / 3 ≈ 2.7` → **3 тика**.

### 3.4 Готовый корабль

По завершении строительства корабль появляется в разделе **«Без флота»** на Космодроме.  
Игрок вручную прикрепляет его к флоту или отправляет отдельно.

## 4. Вооружение

Вооружение устанавливается в слоты **«Место под орудия»** (модуль из TZEconomy).

### 4.1 Типы орудий

| Тип | Орудие | Урон/тик | Дальность | Особенность |
|---|---|---|---|---|
| Кинетика | Рельсотрон | 180 | 3 пк | Игнорирует часть щита. Эффективен vs корпус |
| Кинетика | Автопушка | 80 | 2 пк | Высокая скорострельность. Дёшев |
| Энергетика | Лазер | 150 | 5 пк | Не зависит от манёвренности. Гасится щитом |
| Энергетика | Плазмапушка | 220 | 2 пк | Прожигает броню. Высокий расход энергии |
| Ракетное | Ракеты | 200 | 8 пк | Можно сбить сенсорами. Тратит боеприпасы |
| Ракетное | Торпеды | 400 | 6 пк | Медленные. Только vs крупные цели (Крейсер+) |
| Спецоружие | ЭМИ-пушка | 0 | 3 пк | Отключает щит и реакторы цели на 2 тика |
| Спецоружие | Луч захвата | 0 | 1 пк | Иммобилизует цель на 1 тик (абордаж / торпеды) |

## 5. Флотовая механика

### 5.1 Состав

- Флот объединяет любое количество кораблей под единым командованием
- Нет ограничения на смешение боевых и гражданских
- Флот можно разделить — часть кораблей отделяется в новый флот

### 5.2 Трюм

Трюм флота = сумма грузовых отсеков всех кораблей. Распределение по кораблям не отслеживается — единый пул.

**Колонисты как груз.** Колонисты перевозятся через Колониальный модуль (1 модуль = 5 колонистов, TZEconomy §Модули). С точки зрения флота это груз особого типа. При высадке на необитаемую планету — основывается колония, появляется возможность строить здания и добывать ресурсы. Колонистов также можно перевозить между обитаемыми планетами: для наращивания населения, переселения или эвакуации с планеты близкой к гибели (угасающая звезда, критическая токсичность).

При удалении корабля: если `суммарный трюм − трюм корабля < текущий груз` → удаление запрещено.

### 5.3 Скорость

Скорость флота = скорость **самого медленного** корабля.  
Тип двигателя флота = тип двигателя самого медленного корабля.

**Перегруз трюма** (> 80% заполнения):
```
Скорость × (1 − 0.5 × (загрузка − 0.8) / 0.2)
```
При 100% загрузке скорость падает в 2 раза.

**Типы гиперпривода:**

| Тип | Множитель скорости | Требование |
|---|---|---|
| Ионный | ×1.0 | Гиперсветовой модуль |
| Ядерный | ×1.5 | Гиперсветовой + Атомный реактор |
| Термоядерный | ×2.5 | Гиперсветовой + Атомный реактор ×2 |

## 6. Боевая система

### 6.1 Общий порядок боя

Бой происходит **пошагово** — один тик = один раунд.

```
1. Сближение    — флоты сближаются, пока дальность ≥ дальность орудий
2. Открытие огня — каждый корабль стреляет из всех орудий
3. Приоритеты   — по умолчанию: сначала уничтожить мелкие корабли (меньше у.е.)
4. Применение урона — сначала щит, потом броня, потом корпус
5. Уничтожение  — корпус ≤ 0 → корабль уничтожен
6. Проверка морали — если потери > 30% флота за 1 тик → флот отступает
```

### 6.2 Порядок поглощения урона

```
Входящий урон → Щит (если есть) → Броня (если есть) → Корпус
```

- **Щит** восстанавливается каждый тик на 10% от максимума (если не пробит в этом тике)
- **Броня** не восстанавливается в бою — только в доке
- **Корпус** не восстанавливается в бою

### 6.3 Манёвренность и уклонение

Кинетические орудия (Рельсотрон, Автопушка) и Ракеты могут промахнуться:

```
Шанс попадания = 1 − (манёвренность_цели / 20)
```

Пример: Корвет (манёвренность 9) → шанс попасть 55%.  
Дредноут (манёвренность 1) → шанс попасть 95%.

Лазер и Плазмапушка не зависят от манёвренности — попадают всегда.

### 6.4 Приоритеты атаки

По умолчанию флот атакует цели в порядке:

1. Корабли с наименьшим классом (у.е.) — добить мелких первыми
2. Наиболее повреждённые корабли одного класса — дожать

Игрок может изменить приоритет вручную до начала боя.

### 6.5 Атака планеты (бомбардировка)

Флот может атаковать **планету с орбиты**. Порядок устанавливается игроком:

| Действие | Эффект |
|---|---|
| Уничтожить флоты противника | Сначала бой с флотами в системе |
| Бомбардировка | Каждый тик: −(суммарный урон флота × 0.01) % населения и зданий |
| Высадка десанта | Требует Десантный модуль. Захват колонии если население подавлено |

**Захват без бомбардировки:** если десант превосходит численно — колония сдаётся без разрушений.  
**После бомбардировки:** здания и население частично уничтожены, но штурм проще.

### 6.6 Отступление

Флот может получить приказ на отступление в любой момент боя.  
Отступление занимает **1 тик** — в этот тик флот получает урон, но не стреляет.  
Корабли с манёвренностью ≥ 7 могут уйти в 0.5 тика (урон вполовину).

### 6.7 Пиратство

Режим «Пиратствовать» (команда из Космодрома):

- Флот атакует корабли и флоты в системе, чья **боевая мощь < 70% от мощи пирата**
- Избегает боя с равными (70–130%) и превосходящими (>130%)
- Захватывает груз уничтоженных кораблей (перегружает в свой трюм)
- Не атакует планеты и не взаимодействует с космодромом
